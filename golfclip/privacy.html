プライバシーポリシー

制定日：2026年9月6日

「GolfClip」（以下「本アプリ」）は、個人開発者（以下「開発者」）が提供するiPhone向けゴルフスイング自動クリップアプリです。本ポリシーは、本アプリが取得・利用する情報について説明するものです。

1. 動画・写真ライブラリ（PhotosUI / AVFoundation）

本アプリは、ユーザーが写真ライブラリから選択した練習動画を読み込み、端末上でスイング区間の自動検出・クリップ切り出しを行います。読み込んだ動画および切り出したクリップが開発者側のサーバーに送信されることはありません。切り出したクリップをユーザーが保存操作を行った場合、その動画は端末の写真ライブラリ（カメラロール）に保存されます。

2. ポーズ推定（MediaPipe / 姿勢ランドマーク検出）

スイング区間の自動検出のため、動画フレームから人物の姿勢ランドマーク（関節位置等）を機械学習モデル（MediaPipe）で解析します。この解析はすべて端末上で完結し、映像データやランドマーク情報が外部サーバーに送信されることはありません。

3. Google Driveへのバックアップ（PRO機能）

本アプリのPRO機能をご購入いただいたユーザーは、切り出したスイングクリップをご自身のGoogleアカウントのGoogle Driveに保存できます。この機能では、Google Drive API の drive.file スコープ（本アプリが作成したファイルにのみアクセス可能な限定的な権限）を使用しており、ユーザーのGoogle Drive内の他のファイルにアクセスすることはありません。

本アプリによるGoogleユーザーデータの取得・利用・保存・共有は、Google API Services User Data Policy（Limited Use要件を含む）に準拠します。取得した認証情報（アクセストークン・リフレッシュトークン）は端末内のKeychainにのみ保存され、開発者側のサーバーに送信・保存されることはありません。

4. 購入情報（StoreKit）

本アプリ内の有料機能（買い切り型のアプリ内課金）の決済処理は、Apple社が提供するStoreKitを通じて行われます。開発者は購入者の氏名・住所・決済情報などの個人情報を取得・保持しません。

5. 広告関連識別子・トラッキングデータ

本アプリは広告配信のため、Google AdMobを利用しています。ユーザーがApp Tracking Transparency（ATT）の許可ダイアログで「トラッキングを許可」した場合に限り、IDFA等のトラッキングデータがGoogle AdMobに提供されます。許可しない場合、トラッキング目的でのデータ提供は行われません。

また、EEA（欧州経済領域）・英国等、GDPR等の地域規制が適用されるユーザーに対しては、Google User Messaging Platform（UMP）による同意フォームを表示し、広告に関する同意取得を行います。

なお、ATTの許可状況にかかわらず、広告の配信・不正防止・パフォーマンス測定のため、Google Mobile Ads SDKは以下のデータを収集する場合があります。

  • デバイス識別子（広告識別子等）
  • IPアドレス（おおよその地域の推定に使用されます）
  • 広告の表示回数・タップ等の操作データ
  • クラッシュ情報・パフォーマンス情報等の診断データ

Googleによるデータの取り扱いの詳細は、「Google のサービスを使用するサイトやアプリから収集した情報の Google による使用」およびGoogleプライバシーポリシーをご参照ください。

6. 分析・クラッシュ収集について

本アプリは、Firebase等の第三者製アクセス解析SDKを導入していません。クラッシュ情報については、Apple標準の仕組み（App Store Connect経由のクラッシュレポート）のほか、第5項に記載のGoogle Mobile Ads SDKが、SDK自体の品質改善のためにクラッシュ情報・パフォーマンス情報を収集する場合があります。
